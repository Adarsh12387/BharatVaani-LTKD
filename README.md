# (BharatVaani: A Multilingual Indic Corpus and Latent Text-Guided Knowledge Distillation for Direct Speech-to-Speech Translation
The main contributions of this paper are as follows:
*{BharatVaani}\footnote{\url{https://huggingface.co/datasets/latentvector/BharatVaani}}, a multilingual parallel speech corpus comprising approximately $732$ hours of aligned speech across $35$ Indic languages.

*We introduce a scalable pipeline for constructing multilingual parallel speech corpora and propose an Adaptive Sliding Window Alignment Strategy for accurate cross-lingual speech alignment.
*We propose Latent Text-Guided Knowledge Distillation (LTKD), a framework for fully textless DS$2$ST that distills latent linguistic knowledge from a multilingual teacher into an S$2$UT student.
*We conduct the first large-scale DS$2$ST evaluation across $34$ Indic languages to English, including $20$ not represented in benchmarks such as FLEURS, showing that multilingual LTKD narrows the gap with text-supervised baselines and generalizes to unseen languages.
